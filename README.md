# Climate Space Zimbabwe

Climate Action meets Intelligence. A youth-led movement fusing Artificial Intelligence with Creative Arts to build climate resilience in Zimbabwe.

## 🚀 Overview

Climate Space Zimbabwe leverages cutting-edge technology and artistic expression to address the urgent challenges of climate change. Our platform provides smart agricultural tools, a digital creative gallery, and community-driven resources to empower Zimbabwean farmers and youths.

## 🛠️ Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Components**: Radix UI + Custom Components
- **Deployment**: Vercel (recommended)

## 📂 Project Structure

- `src/app`: Next.js App Router pages and layouts.
- `src/components`: Reusable UI components.
- `src/lib`: Utility functions and shared logic.
- `public`: Static assets (images, icons).
- `docs`: Detailed project documentation.

## 🚦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone https://github.com/PraiseTechzw/climate-space-zimbabwe-web.git
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
